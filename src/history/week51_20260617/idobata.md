## 進行中のタスク・議論中のPR

### [PR #497](https://github.com/digitaldemocracy2030/idobata/pull/497) トップページ表示と GitHub App 秘密鍵設定を改善

- **貢献者:** 101ta28 さん
- **変更内容:** (+229, -118, 12ファイル更新)
- **主な修正・追加点:**
  - 最新の質問がない場合でもトップページの表示ができるように改良  
    → ユーザがよりスムーズに質問・テーマを閲覧できるようになります。
  - リンク先を柔軟に指定できるよう、質問カードやテーマカード周りを調整  
    → URL を自由に設定可能にし、運用上の自由度が上がっています。
  - フロントエンドのHTTPクライアントでGETリクエストにキャッシュ無効化オプションを設定  
    → 最新情報を優先して取得する方針ですが、パフォーマンスへの影響にも注意が必要です。
  - GitHub App の秘密鍵を環境変数・base64化環境変数・設定ファイルパスから柔軟に読み込めるよう変更  
    → 運用環境ごとの秘密鍵管理がしやすくなります。
  - GitHub 関連の環境変数をログに出力していたDebugログを削除  
    → セキュリティリスクを低減します。
  - `idea-discussion` の `Problem` / `Solution` / `SharpQuestion` の型を拡張  
    → データ管理において拡張性と表現力が向上しますが、既存データとの互換性やAPI利用箇所への影響を要確認です。

- **議論ポイント:**
  - フィールド名や `required` 設定の変更に伴う既存データへの影響について
  - GET 全体にキャッシュ無効化(`cache: "no-store"`)を適用する方針の是非  
    → 最新性重視か、パフォーマンス重視かを考える必要があります。
  - GitHub App 秘密鍵の読み込み手順が運用上問題ないか

- **レビュー・フィードバック募集:**
  - 稼働中の環境でのGitHub App設定をどうするか  
  - `idea-discussion` スキーマ変更のテストケースや実運用への影響
  - キャッシュ戦略を含めたユーザビリティやパフォーマンスのバランス
